array ex... -> [1, 2, 3]

------------------------------

**static arrays** - fixed size.

change a value:

[1, 3, 3] ✅

add another value:

[1, 2, 3, 9] ❌
 
**dynamic arrays** - can grow or shrink in size.

add a value:

[1, 2, 3, 4] ✅

remove a value:

[1, 2] ✅
