# Arrays

This section contains solutions to array problems, organized into static-array
and dynamic-array concepts.

## Static arrays

Static arrays have a fixed size. Their existing elements can be read or updated,
but the array's capacity does not automatically grow or shrink.

- [Max Consecutive Ones](static-arrays/max-consecutive-ones/Solution.py)
- [Remove Element](static-arrays/remove-element/Solution.py)
- [Replace Elements with Greatest Element on Right Side](static-arrays/replace-elements-with-greatest-element-on-right-side/Solution.py)

## Dynamic arrays

Dynamic arrays can grow as values are added. Python lists behave like dynamic
arrays and automatically manage their internal capacity.

- [Concatenation of Array](dynamic-arrays/concatenation-of-array/Solution.py)
